## Animation library and mapping

Source: https://github.com/catprisbrey/Godot4-OpenAnimationLibraries

Pinned revision: ccc61c4d8cdc1fb7188a60ba4f51f7a3cac51df9

The coursework explicitly requests `BoneMaps/Mixamo BoneMap.tres` and `Libraries/Humanoid/MeleeLib.res`. The animations originate from the referenced Mixamo library. No blanket MIT or CC0 license is asserted for these resources. Upstream's FORMER-README contains a concern about redistributing animation datasets. Therefore the standalone `.res` is not committed here; a script obtains it from the exact coursework source. The deployed demo bundles animation data for playback as part of the application. Do not reuse this repository as a standalone animation asset distribution.
